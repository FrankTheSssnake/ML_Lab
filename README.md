Experiment scripts for machine learning coursework and projects.

## Overview

This repository contains Python scripts for exploring and implementing various machine learning concepts and algorithms.

## Structure

- **experiments/**: ML experiment notebooks and scripts
- **data/**: Datasets used in experiments
- **utils/**: Helper functions and utilities

## Getting Started

1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run experiments from the command line or Jupyter notebooks

## Requirements

- Python 3.8+
- See `requirements.txt` for package dependencies
